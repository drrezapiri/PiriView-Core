# PiriView Core

PiriView Core is a research-oriented desktop workstation for medical image visualization, segmentation, and quantitative analysis.

The project aims to provide a lightweight and intuitive environment for working with medical imaging datasets while keeping common research tasks within a single application.

## Project status

PiriView Core is currently in early public development.

The first development milestone (`v0.1.0`) will provide a basic DICOM image viewer with:

- DICOM series loading
- Axial image display
- Slice navigation
- Window and level adjustment
- Zoom
- Pan

Additional functionality will be introduced incrementally during development.

## Planned scope

The planned PiriView Core functionality includes:

- DICOM and NIfTI image support
- Multiplanar reconstruction
- Manual and semi-automatic segmentation
- Segmentation import and export
- Basic segmentation operations
- Quantitative measurements
- Segmentation statistics
- 3D visualization
- Research-oriented data export

## Development

PiriView originated as a privately developed medical-imaging research application.

PiriView Core is a separately maintained research edition whose core functionality is being developed publicly from September 2026 onward.

The project is under active development and is not intended for clinical diagnostic use.
